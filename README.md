# Plataforma de treinamento futebolístico

This is a code bundle for Plataforma de treinamento futebolístico. The original project is available at https://www.figma.com/design/M1FmsHE3Ki97f1SZhzGz9V/Plataforma-de-treinamento-futebol%C3%ADstico.

## Running the code

Run `npm install` to install the dependencies.

Run `npm run dev` to start the development server.

Run `npm run build` to create a production build.
